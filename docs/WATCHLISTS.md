# Instrument watchlists

Create a watchlist from the register, review queue or maturity screen. Select it under Current watchlist, then use Watch beside an instrument to add it. Unwatch removes its membership.

Enable Watchlisted instruments only to show members of the selected list. Bank, search, status and date filters continue to apply. Totals and the register CSV reflect the resulting rows. Clear filters also disables the watchlist filter. Select the list again after a reload to work with its members.

To rename a list, enter its new name in Watchlist name and choose Rename using name. Delete watchlist removes that list and its memberships. Export watchlist IDs downloads the list name and instrument IDs, including any historical IDs that remain in browser storage.

Each account can keep five lists with up to 500 instruments each. Watchlists stay in local browser storage. Clearing that storage removes them. A separate demo scope keeps sample memberships apart from signed-in accounts. Open tabs receive changes through browser storage events.

Saved filter presets and copied filter links retain their existing filter fields. Watchlist selection is a separate browser preference. Recipients of filter links select their own watchlists. All instrument data continues to follow the account's workspace permissions.
